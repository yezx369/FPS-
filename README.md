# FPS_Game_01

一款用 Unity 制作的开源单机第一人称射击游戏（Windows 版）。免安装、解压即玩，约 80 MB，Win10/11 64 位，集显也能流畅运行。

## 下载与安装

1. 到本仓库 **Releases** 页面下载 `FPS_Game_01_Windows_v0.5.2.zip`
2. 解压到任意目录（不要只解压 exe，`FPS_Game_01_Data` 文件夹必须和 exe 在一起）
3. 双击 `FPS_Game_01.exe` 开始游戏

> 如果杀毒软件误报，把整个文件夹加入白名单即可（Unity 打包的 exe 偶尔会被误判）。

## 内容

- **10 个关卡**，含仓库、小镇街区等场景
- **15 把可用武器** + 1 个缴获解锁槽：AK-47、沙漠之鹰、SPAS-12、M249 SAW、MP5、AWP、M1911、M32 榴弹发射器、RPG-7、火焰喷射器、M134 加特林、战术盾牌、战术弩、破拆斧、M-9 军刀
- **射击手感**：按住开火时可用鼠标自由修正弹道、压后坐力；右键瞄准、中键举盾
- **敌人 AI**：巡逻 — 警戒 — 追击 — 攻击 — 死亡 状态机，含猎犬、火箭筒兵、喷火兵等单位，击倒后有物理倒地效果
- **地图安全**：出生点带重叠检查，被楼体/车辆占位时自动就近寻找空位；掉出地图（y=-10）立即判死

## 操作按键（PC）

| 功能 | 按键 |
|---|---|
| 移动 | W A S D |
| 转视角 | 鼠标移动 |
| 开火 | 鼠标左键（按住连发） |
| 瞄准 | 鼠标右键（按住） |
| 举盾防御 | 鼠标中键（盾牌武器时） |
| 跳跃 | 空格 |
| 冲刺 | 按住 Shift |
| 蹲下 | C 或左 Ctrl（按住保持） |
| 换弹 | R |
| 近战 | V |
| 切枪 | Q |
| 切换射击模式 | B |
| 直接选武器 | 数字键 1~0（第 1~10 槽） |
| 投手雷 | G |
| 投燃烧瓶 | F |
| 互动 / 拾取 | E |
| 暂停 | Esc |
